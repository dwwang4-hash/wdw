# 独立峰值与固定矩阵扰动预登记（2026-10-13）

## 峰值比较

在非零跳跃分片制造解上增加两侧相同的零边界峰
h=16×.75×x(1−x)y(1−y)exp(−((x−.46)²+(y−.55)²)/w²)。w=.12,.06；β=(1,1),(1000,1)。值跳跃不变，通量增加(β右−β左)h_x|Γ。根据公式和独立差分测试验证，不能沿用旧g_q。

固定每侧128特征，scale=2,4；局部坐标，balanced尺度、平方边界/界面权重50、ridge0、rcond1e−12。scale4是为较快变化预设的对照，来自新模型频率考虑；不按峰值测试结果选取。特征数128是CPU可负担且上一轮平滑基线验证过的规模，并不保证峰值可表达。

方法A/B/C/D/D_unused。D_unused仅在组预算指标中排除已经选入训练的候选点，不改变每组位置抽样。unused池不是最终独立验证集，也不满足自动iid假设。旧D默认all保持不变；所有方法同seed隐藏参数相同。固定**标量方程预算**，三轮/六轮，最终行数1232/1904，外边界240行固定；A/B/C最终物理点1104/1680，D可变化且须报告。候选池每侧2048、界面1024，探索.2，最低新增(16,16,8)。

两峰宽×两β×两scale×两轮数×五方法×五种子=400次完整算法运行。独立测试每侧161×161中点、界面521中点；额外每侧81×81测试用于网格敏感性，均不参与选点。记录两网格误差及变化，不把细网格一定当作精确连续积分。保存每个模型的精确解/数据网格；代表解固定w=.06,β=(1000,1),scale4,六轮,seed11，展示所有方法，不挑最好。

报告全部配置均值/样本标准差、D和D_unused相对A/B/C配对变化、物理通量和完整成本；不同scale的表现均保留。实验不设“D必须赢”验收，不因效果不足另选峰位置。

计时补充：峰值与谱实验起初并发启动，因此峰值前段时间可能受另一任务影响，主表total_seconds只作运行记录。两项结束后，固定w=.06,β=(1000,1),scale4,六轮、五方法×五种子，共25次算法在无其他本项目计算任务并发时重新计时；使用独立run_id，精度与主运行系数校验一致。该重复只用于固定场景的成本检查，不宣称覆盖所有模型的公平效率。

## 右端扰动与SVD阈值

固定平滑非零跳跃模型β=(1,1000)、内部368/侧+界面128、scale2、每侧N=64/128/256、五种子。保存加权矩阵的完整奇异值。rcond=1e−14,1e−12,1e−10，各固定阈值下求最小二乘。

相对右端扰动1e−8，两个方向：最小保留左奇异向量（展示系数敏感性上界的可达性）与独立随机单位方向（种子[seed,700]）。每配置报告‖δc‖/‖δd‖、理论1/σ_min_retained、函数预测变化、系数范数、原始/保留条件数、秩；加入已被截断的方向时比较是否受抑制。各组矩阵不扰动；不把固定子空间结论外推到矩阵/秩变化。3宽度×5种子×3阈值×2方向=90组扰动观察，另保存15组谱。不是新的收敛定理。
