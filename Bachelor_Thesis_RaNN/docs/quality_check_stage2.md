# LRNN、采样与敏感性阶段质量检查（2026-10-13）

## 已完成验收

- 13项单元测试：原5项、非零跳跃制造解/局部链式导数/解析基精确矩阵/Poisson极限4项，以及预算守恒/无重复/配对特征/初始点前缀4项。没有仅用相同公式自我比较。
- exp02：150次；exp03：180次完整算法运行（自适应方法每次含4次最小二乘）；exp04：285次。共615次新增实验运行，五个公开固定种子，失败数0。ok仅指正常运行且指标有限，不能写作所有方案高精度或优势通过。
- 所有case均保存状态、配置、原始CSV、独立误差/物理通量/秩/条件数/时间；每组均值及样本标准差保留。输出系数NPZ可按case_index和固定参数重建解。图表由CSV重绘，文件哈希检查保证重绘不改变原始CSV。
- 两种预算分别守恒；单个界面点贡献两行，明确报告物理点和方程数。静态A/B与C/D隐藏特征同seed配对；B包含C/D初始点前缀。A使用完整确定网格，不与随机初始点混称同一点集。
- 独立测试网格从未参与选点/选轮次；固定候选池之后包含已用于训练的点，下一轮池RMS可能乐观，已列限制，尚未采用独立监测池。
- total_seconds包含候选评估、预算/抽样及所有重求解，排除最终独立验证/绘图。单次solve_seconds与完整算法时间分开。

## 结论审查

允许写：当前平滑直线制造解与预设参数下，D的解误差未胜A/B、额外成本更高；固定更多界面点也可取得比消融更好的平均解误差；宽度和scale影响显著；尺度平衡可改善解却恶化物理通量；增宽伴随病态和秩截断。只做描述性比较，不把3×5配对当作15独立种子。

不允许写：D在一般椭圆界面PDE上无效/有效的定理；发现原创采样算法；局部方法比全局方法公平更快；岭必然提升准确度；增加点数必然改善解；尺度平衡消除全部病态；目前已有完整论文/原文严格复现/Windows实机验证。

exp04为看到负面结果后登记的探索性扫描，不能把扫描中较好参数改写为exp03事先设置或进行未校正的确认性推断。高对比度64特征物理通量RMS可大于跳跃幅值，解误差小不代表通量数据满足良好。
