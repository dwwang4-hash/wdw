# 采样比较预登记（界面基线通过后，2026-10-13）

本轮使用非零跳跃模型，β=(1,1),(1000,1),(1,1000)，每侧64随机特征、scale2、balanced尺度、平方组权重50、无岭、rcond1e−12。不是原文复现。每种策略五固定种子。参数固定后再运行，不根据测试真解选择轮次或调整超参数。

主比较A固定完整矩形网格、B固定随机、C仅内部PDE残差抽样（固定组预算、界面均匀增量）、D联合指标分配。初始内部128/侧+界面32，三轮；静态参考每轮(80,80,32)。A/B最终内部368/侧（16×23完整网格）+界面128，总内部/界面物理点864；外边界240固定，总点1104，标量方程1232。

两种独立预算：points每轮新增192物理点；equations每轮新增224标量行、界面点成本2。前者D可改变方程数，后者D可改变物理点数，但对应主预算严格守恒。A/B/C静态最终点和行相同。报告两者，不把“相同点数”写成“相同行数”。

初始点、候选池（每侧2048，界面1024）、隐藏特征、随机抽样流在同seed方法间共享。C/D重用既有特征；候选点不放回，每组保持最低新增(16,16,8)，80%残差比例+20%均匀探索。D指标η_i=RMS(r_i/β_i)，η_Γ=RMS(sqrt(r_u²+(r_q/β_max)²))，与本轮固定组尺度一致；这取代总体计划中按f-RMS的候选尺度，本轮选择理由为隔离采样效应，不在看到采样结果后调尺度。目标是偏重高残差的经验均方，**没有逆密度重要性加权，不声称近似固定均匀积分**。

验证固定独立83×83/侧、界面257点、边界83/段，不参与指标计算。计时total_seconds从点生成开始，到最终求解和诊断结束，包含候选评估和4次求解，排除最终验证/绘图。多轮重求解比A/B贵，是真实成本，不予隐藏。
