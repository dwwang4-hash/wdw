# 研究计划与可行性论证（2026-10-13，起步版）

暂定题目：《基于自适应采样的局部随机神经网络求解椭圆型界面问题的数值研究》。建议暂保留，开题定位为**已有方法的独立实现、配置点策略比较和稳定性分析**。不以提出原创算法为完成条件。导师尚未确认题目、期限和学校格式。

## 十项可行性判断

| 问题 | 结论及实施方式 |
|---|---|
| 数学准备 | 多元微积分（链式法则、散度、法向）、线性代数（最小二乘、奇异值）、数值分析（截断误差、条件数）、PDE（Poisson、Dirichlet、分片光滑与跳跃）。Sobolev空间和Galerkin弱形式用于阅读，不要求完全重建原文理论。 |
| 本科周期 | 若有约10—12周、每周10—15小时，二维直线界面与CPU小规模实验具有可行性；该时间是保守计划假设，非用户已确认期限。前四周必须取得可重复基线，否则收缩方向。 |
| GPU | 不需要。隐藏参数固定，主计算为CPU稠密最小二乘；以总特征64—512、总配置点约500—6000起步，按实测内存和时间扩展。 |
| 外部数据 | 不需要，全部算例用制造解。文献PDF用于算法核查，不是训练数据。 |
| 真解验证 | 先验证正弦Poisson的二阶差分收敛，再验证分片制造解的PDE、边界、值跳跃和通量跳跃；独立于训练点计算误差。 |
| 可独立实现 | 五点差分、tanh解析导数、SVD最小二乘、双子域强形式配置、A/B/C/D采样策略。DG、PG、Schwarz仅选择一个小算例学习/复现，不同时重建全部。 |
| 可解释/证明 | 五点格式一致性；当前正弦解的精确离散误差与二阶收敛；矩阵组装；固定矩阵右端扰动界；条件数平方现象；岭正则化奇异值滤波。不能据此声称证明随机网络全PDE收敛。 |
| 贡献归属 | 固定随机隐藏层、局部网络、界面耦合、残差采样均已有。可能形成的个人工作是独立实现、统一公平比较、负面结果、尺度/预算分配消融及简化稳定性推导。D只能称“候选联合策略”，优越性及新颖性均待验证。 |
| 主要风险 | 高对比度行尺度失衡；矩阵近秩亏；采样集中而覆盖不足；易算例无法区分策略；自适应改变有效损失；独立验证不足；正式版与预印本公式不同；新文献已覆盖候选策略。 |
| 缩小范围 | 先只做二维、直线界面、分片常数、tanh单隐层、固定特征。再收缩为Poisson配置点和稳定性研究。圆界面、复杂DG、Schwarz及多层增长不属于必达目标。 |

## 三层目标

最低：正确实现基础RaNN；Poisson和直线界面制造解验证通过；五个固定种子；误差、界面指标和数值秩有记录。初始时仅完成Poisson；后续已完成直线界面LRNN、零/非零跳跃、五种子和不同β实验，见interface_results。

标准：双子域LRNN、A/B/C/D相同最终预算比较、参数敏感性、高对比度、消融、CPU成本和简化数学分析；根据结果写完整本科论文。

拓展：检索排除重复后研究D预算分配，若在合理基线、多种子、多算例下有稳定收益再作为方法改进。失败或收益不足也应形成可接受的标准成果。

## 下一步决策

优先实现双子域强形式LRNN。使用解析导数的基础版本应标为独立实现，不能称严格复现LRNN-FD。原文FD导数版本需另设模式、步长敏感性与公式核查。预印本(3.5)的通量矩阵印刷式未显式带β、边界块表达也需核对；物理条件必须按完整模型组装，不机械复制疑似漏项。
