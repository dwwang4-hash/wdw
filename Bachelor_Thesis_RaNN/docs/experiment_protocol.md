# 实验协议（先登记，后实现）

## 已执行exp01

u=sin(πx)sin(πy)，f=2π²u，零Dirichlet。FDM n=15,31,63,127。基础强形式RaNN：N=64,128；w,b~U[−4,4]；1024内部随机点；每边80个中点，共320边界点；λ_b=10；gelsd，rcond=1e−12，无岭；种子11,23,37,51,71。边界训练点固定，内部点流使用SeedSequence([seed,100])，特征流用seed。更改特征数时配置点保持不变。

RaNN验证：81×81内部中点网格，与训练点独立；每边81个边界中点，与训练边界不同。FDM误差评估在自身节点上，残差为**离散相对线性系统残差**；RaNN残差为**连续算子独立点RMS**，二者不可直接比较。FDM未知数是网格值，RaNN未知数是输出系数，本实验不是相同预算效率比较。

输出CSV记录每一次随机运行；汇总为均值和ddof=1样本标准差。计时包含组装、SVD求解和奇异值诊断，排除验证/绘图；BLAS线程固定1。另行效率实验才计入端到端运行。当前条件数为**加权矩阵**的σ_max/σ_min，另报阈值下保留条件数和秩。训练目标为块均方和；日志`weighted_training_rms`还除以总行数，不能与目标值直接混用。

## 后续公平比较方案

1. 先固定制造解、β、隐藏特征与边界点；A/B/C/D在同一个seed内共享这些量。共同初始内部/界面点，C/D使用相同候选池、迭代轮数和新增总预算。
2. 区分“配置点数”和“标量方程数”：一个界面点贡献值与通量两行，报告两种计数。主比较固定最终内部点+界面点总数，并同时报告方程数；补充固定标量行预算比较，以排除D增加方程数的优势。
3. A均匀、B随机：最终相同预算一次求解；C仅按PDE残差选择内部点，界面新增数预先固定；D动态分配Ω₁/Ω₂/Γ预算。另给静态界面比例扫描的合理基线，避免只战胜差的固定比例。
4. 固定边界点和组权重。每组目标按点数归一化，避免单纯新增点隐式提高损失权重。若分布改变，明确目标究竟是强调高残差的经验损失还是近似原均匀积分；后者须使用带均匀混合下限的采样概率和逆密度权重。两种目标不可混写。
5. 候选指标不得使用精确解误差。预设尺度s_i=max(RMS(f_i),1)、s_u=max(RMS(g_D),RMS(g_u),1)、s_q=max(RMS(g_q),β_max/L,1)，且固定后不能逐方法调节。记录该尺度可能掩盖物理高对比度误差的风险，同时报告未归一化指标。
6. 候选D：η_i=RMS(r_i/s_i)；η_Γ=√mean((r_u/s_u)²+(r_q/s_q)²)。每轮先分配各类最低新增数，再将剩余预算按(η_k+ε)^p比例分配，用最大余数法取整数，p初取1。各类内以80%残差概率、20%均匀探索采样，避免塌缩；均匀候选池和最低覆盖点始终保留。全零指标时退回均匀分配。
7. 独立验证点从不参与采样；另设独立调参模型/点集。迭代次数固定，避免根据测试真解挑选最佳轮次。若设置停止条件，只用独立开发验证残差并报告其成本，不反复查看最终测试集。
8. 所有异常、秩下降、非有限值、残差增大保留在原始表，记录状态；不得只删除失败种子后统计。报告配对误差差值、成功数和均值/标准差；五种子小样本不作强统计普适结论。

## 预定实验清单

| 实验 | 变量/范围（初始登记，可按CPU实测缩减并记录） | 主要问题 |
|---|---|---|
| exp01正确性 | 已执行Poisson FDM/RaNN；LRNN待补充 | 公式、二阶差分和随机特征导数 |
| exp02界面 | β₁/β₂=1,10,100,1000；另外反向比值；零及非零跳跃 | 正确界面条件与高对比度稳定性 |
| exp03策略 | A/B/C/D；总点500,1000,2000；固定轮数3 | 等预算误差、方程数、额外成本 |
| exp04敏感性 | 每侧N=32,64,128,256；scale=.5,1,2,4,8；点数约特征总数的2,4,8倍；界面权重1,10,50,100；ridge=0,1e−12,1e−9,1e−6（需结合矩阵尺度） | 参数、病态性及误差饱和 |
| exp05消融 | D去PDE指标、去界面指标、去探索、固定预算比例；公平保持总预算 | 指标各部分是否必要 |
| 效率 | 完整自适应时间（采样+候选评估+多次组装求解）与最终误差；预先登记精度目标 | 精度收益能否抵偿额外成本 |

每项至少五固定种子，资源允许十种子。初期平滑模型后另加局部峰或界面附近快变化模型，避免易算例掩盖采样作用。圆界面和FD原文算例只在直线模型验收后实施。
