# 数学本科论文科研项目

本仓库用于保存 Bachelor_Thesis_RaNN 云端科研项目的迁移快照。

项目包括 Python 源码、原始数值结果、图表、论文 v3 和 Windows 迁移说明。项目位于 `Bachelor_Thesis_RaNN/`。

迁移中的科研结论保持原样：联合残差采样尚未稳定优于合理静态基线；不声称原创算法、严格作者复现或学校已批准提交。

## 下载与运行

点击本页绿色 **Code → Download ZIP**，解压后在 VS Code 中打开 `Bachelor_Thesis_RaNN` 文件夹。

请先阅读项目内的 `docs/Windows本地运行说明.md`。Python 依赖安装前可用标准库脚本 `scripts/verify_migration.py` 校验迁移清单。Windows 需要自己创建 `.venv`，不复制 Linux 虚拟环境。

当前提交为迁移准备，未重新运行科研实验。完整逐字聊天、未保存的中间状态及 6 份旧阶段 ZIP 不包含在这个日常项目快照中；旧论文源版本保留在项目 `thesis/versions/`。

项目内迁移文档记录的是 2026-10-18 打包时状态，其中“未连接 Git 仓库”描述原云端工作区；本仓库为随后经用户确认创建的 GitHub 副本。
